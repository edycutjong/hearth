The gate · nothing is stamped on the model's word

The model proposes. Code decides what gets stamped.

Nemotron 3 Super reads the transcript and proposes promises with a strict json_schema. Its card does not list Hindi, so nothing it says is shown until code checks it: the quote must be verbatim in the transcript, the amount is parsed from the quote's own words, and the date is resolved from the quote and the note's own date.

How it keeps

Six parts. Each one is a file in the repo.

Stored as codes, not audio

NanoCodec turns each note into 13 codebooks × 12.5 frames a second, packed 11 bits each into a .hct file with its gain and a sha256. Above: the 60-second sample note, 753 frames, 13,532 bytes.

nemo-nano-codec-22khz-1.78kbps-12.5fpsworker/worker.py

Deleted only after a check

The Job decodes the codes and transcribes them again. At 5 % word drift or less — and no segment of 8 words or more over 30 % — the app deletes the raw upload after a 24-hour grace and shows HEAD → 404; otherwise the original stays.

nemotron-3.5-asr-streaming-0.6bhi-IN · 1.12 s

The model proposes; code decides

A promise is shown only if its quote is verbatim in the transcript; the amount and the date are re-derived from that quote.

nemotron-3-super-120b-a12bjson_schemasrc/lib/gates.ts

Leave with everything

Delete-all shows the storage listings come back empty. Export zips the codes, transcript, memory, the .ics and decode.py — which rebuilt the sample's audio without Hearth at 57.5 dB SNR against the Job's own decode.

Questions a judge would ask

Before you press play.

Is that a real family's voice?

No. Every voice on this page is FLEURS read speech (Google, CC BY 4.0), labelled where it plays — “It is not a family note and is never presented as one.” The consented, actor-voiced family sample replaces it once it is recorded.

— README · See it in Action

What happens to the raw audio?

It is kept 24 hours so you can compare, then deleted — and Hearth shows you the storage answering 404. If the round trip changes more than 5 % of the words (or more than 30 % of any segment of 8 words or more), the original is kept instead, and you can delete it yourself. Turn deletion off and originals stay in your space, counted as stored audio.

— the app's first screen · src/components/app/Agree.tsx · src/lib/pipeline.ts

What does Token Factory see — and keep?

Transcript text only, never audio. Token Factory may keep prompts and outputs for Speculative Decoding (stored in Finland, never used for training) unless Zero Data Retention is confirmed for the organisation; until then, non-sample spaces see this sentence and must opt in before any transcript text is sent.

— README · Honest limits 7

Why CPU — and why does a keep take minutes?

Both NVIDIA speech models run on cpu-d3 (4 vCPU): the ASR at a real-time factor of 0.16, the codec round trip at 0.63. Neither card states CPU support, so every speed number here is ours. Most of the ~6.6 minutes is the Job starting (≈164 s to a running container in the benchmark Job) and loading two models; the work itself is about a minute for a 60 s note.

— README · Honest limits 1–2 · bench/results/latest.json

Why no agent runtime — NemoClaw, OpenShell, Hermes Agent?

They are named in the track text and deliberately not used: the one flow — forward, keep, remember, find, delete or export — needs no agent runtime, and judges could not install them. Nemotron 3 Super is called with a strict json_schema, and code checks every proposal before anything is shown.

— README · NVIDIA + Nebius Integration

Can the codec change what she said?

Yes — it is lossy. Across 20 FLEURS hi_in clips the round trip adds 4.09 WER points (8.74 → 12.83 %), one normal-level clip got worse (13.0 % → 47.8 %), and a very quiet one went 38.9 % → 55.6 %. That is why the drift gate keeps drifting originals, and why every reminder says “as transcribed” and plays its source.

— README · Honest limits 4 · FEEDBACK.md §9
